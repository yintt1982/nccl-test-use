# Glossary Map

## Contexts

- [Network Data Analysis](./GLOSSARY.md): terms for passive packet observation and network analysis.
- [NCCL Test Observability](./docs/nccl/GLOSSARY.md): terms for configuring benchmark runs, collecting NCCL runtime events, and interpreting reports.

## Relationships

- **NCCL Test Observability → Network Data Analysis**: NCCL Profiler events describe software communication work; packet and device telemetry describe observed network activity. One source does not prove the other.
